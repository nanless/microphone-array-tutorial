# GitHub 首页：调研与改版依据

首页承担三件事：让第一次访问的人迅速弄懂主题，给出一个立刻能验证的现象，告诉读者接下来该读哪几章。上一版在同一页详细解了一个高低双音题，却把整本书能做什么放得太靠后。这次按“动图演示＋序言＋课程主页”组织；首页实验是入口，原来那道细算题仍在第 1 章。

## 实验设计和证据边界

- 两种节奏有意使用不同包络和音色，长音与成对短音在时间上重叠。16 kHz 下四路到达格数分别为 A 的 0、2、4、6 和 B 的 6、4、2、0；转向 A 时补 6、4、2、0 格，两种声音用同一个处理规则。选中源完整保留，共同延迟 6 点。
- 当对准 A 时，B 的有效时移为 12、8、4、0 格。对 3 kHz 定振幅正弦，相邻时移的相位差是 270°，四个相量相加为零；实际音符有包络，不宣称完全消失。把 B 换成 250 Hz 后，相邻差为 22.5°，不再接近相消。定振幅解析值是 `[(cos 33.75° + cos 11.25°) / 2]²`，约为 82%；带包络的浮点整段读数约 82.1038%。
- 保留比例使用完整尾部下同一声源的浮点平方和比，不能当作响度比或实录降噪量。试听使用单声道 PCM16 混合文件，无各段单独归一化。全书现有练习、音频清单、网页和 PDF 不以 GitHub 首页为源，本次不改它们的计数。

## 同日复审：把实验移出书的主线

初版仍先展示两种合成节奏、再解释四麦怎样补时差，访问者需要读完一个实验才看到书的范围。复审改用一个熟悉的场景贯穿封面和序言：会议桌上的说话声，在四路录音中以不同的时间到达；这给定位和拾音提供共同起点，而通话回声要另外利用播放信号。

- [Ray Tracing in One Weekend](https://raytracing.github.io/) 让封面图紧挨读书入口，并把实验能产出什么与学习路线分开。此次保留可直接开始读的第一章入口，将试听和数值复算移到独立实验页。
- [Nand to Tetris](https://www.nand2tetris.org/) 从读者要做出的系统倒推课程材料。首页路线改成从四路录音到设备验收的四个任务，每个任务下面列实际章节。
- [Stanford CS224N](https://web.stanford.edu/class/cs224n/) 单列先修要求和读者可以使用的课程资源。这里在路线开头明确先看图和听音、何时需要数学附录，并把正式目录与配套代码另列。

新封面和四路波形均为教学示意，无实录或尺寸刻度。上一版的动画、试听文件、计算口径和结果仍可按原路径访问；本轮未改变教材章、图、音频和练习计数。

## 课程页与仓库入口分工

把 GitHub 的 README 缩到选择入口、试听和短序言。完整课程入口用网页呈现：首屏可切换声源和重播传播示意，序言把一次通话拆成三个待查的问题，随后用同源的三段 WAV 比较不同拾音方式，再按任务选章节。原导读仍接在课程区下方，保留旧地址与小节锚点。

课程网页、GitHub 动图和单文件下载版共享同一幅阵列示意。单文件版把三段 WAV 内嵌，下载后无需网络即可使用示意与播放器；章节链接仍去 GitHub。动画按减少动态效果设置切换为静态，左右到达顺序继续用文字呈现。合成音只说明方向对准在该模型中的效果，不代表设备在真实房间里的表现。
