# GitHub 首页：调研与改版依据

首页承担三件事：让第一次访问的人迅速弄懂主题，给出一个立刻能验证的现象，告诉读者接下来该读哪几章。上一版在同一页详细解了一个高低双音题，却把整本书能做什么放得太靠后。这次按“动图演示＋序言＋课程主页”组织；首页实验是入口，原来那道细算题仍在第 1 章。

## 对照阅读

| 一手材料 | 观察 | 用在本首页的决定 |
| --- | --- | --- |
| [Bartosz Ciechanowski，《Sound》](https://ciechanow.ski/sound/) | 开头先给一组能亲耳听到的音；后面再用传播模型解释，并主动区分放慢的动效和真实速度。 | 首屏用动画示意到达先后；紧接可直接播放的单声道对照。动效放慢、路径示意，数值由独立的采样时间轴交代。 |
| [Ström、Åström、Akenine-Möller，《Immersive Linear Algebra》](https://immersivemath.com/ila/) | 交互图、简短序言、可独立查阅的章节目录并存。每章介绍一个读者能带走的概念。 | 让图承担顺序、补偿两种信息；序言连起定位和拾音；四站用具体任务命名，另保留完整目录。 |
| [MIT Missing Semester：课程动机](https://missing.csail.mit.edu/about/) | 用能马上认出的麻烦说明为什么需要这些工具，再列举读者能解决的实际任务。 | 会议桌上的说话和键盘声承担序言的动机。用回声、拖尾、串话等实际现象为工程读者导路。 |

| [fast.ai《Practical Deep Learning for Coders》](https://course.fast.ai/) | 第一屏给出适用读者、用途和课程承诺；安装、案例和课程索引有各自位置。 | 首屏只放主题、能做什么、三个去处。依赖和复算放实验折叠区，不挡住直接试听。 |

| [GitHub 写作与格式说明](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax) | 仓库内资源使用相对链接。README 的资源预览与执行本地网页是两件事。 | 直接显示 SVG，音频用版本化 WAV；互动页只需一个 HTML 文件，明确从文件页下载，不依赖外部网站。 |

## 实验设计和证据边界

- 两种节奏有意使用不同包络和音色，长音与成对短音在时间上重叠。16 kHz 下四路到达格数分别为 A 的 0、2、4、6 和 B 的 6、4、2、0；转向 A 时补 6、4、2、0 格，两种声音用同一个处理规则。选中源完整保留，共同延迟 6 点。
- 当对准 A 时，B 的有效时移为 12、8、4、0 格。对 3 kHz 定振幅正弦，相邻时移的相位差是 270°，四个相量相加为零；实际音符有包络，不宣称完全消失。把 B 换成 250 Hz 后，相邻差为 22.5°，不再接近相消。定振幅解析值是 `[(cos 33.75° + cos 11.25°) / 2]²`，约为 82%；带包络的浮点整段读数约 82.1038%。
- 保留比例使用完整尾部下同一声源的浮点平方和比，不能当作响度比或实录降噪量。试听使用单声道 PCM16 混合文件，无各段单独归一化。全书现有练习、音频清单、网页和 PDF 不以 GitHub 首页为源，本次不改它们的计数。
