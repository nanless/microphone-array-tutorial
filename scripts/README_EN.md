This directory contains all **92 numbered pedagogical figure generators**, the **interactive static course website builder (`build_site.py`)**, the **tagged accessible A4 monograph PDF builder (`build_pdf.py`)**, and the **automated repository-wide release gate (`quality_check.py`)**. Algorithmic and engineering Python cores live under `codes/`; both groups of scripts must be executed from the **repository root** using the primary `.venv` virtual environment.

Authoritative single-chapter experiment runners are organized across [Chapters 0–15 and Chapters 16–17 (Appendices A/B)](../codes/chapters/README_EN.md); the shared directory `codes/chapters/ch00/` also hosts Chapter 0's mathematical foundation kernels and 16 exercises, cross-chapter exercise suites, repository-wide source lockfiles, and the main 109-clip audio manifest. Legacy `codes.examples` and `codes.array_tutorial` import paths have been removed. Audio suites, the room simulation generator, and upstream contract probes bind source file paths and SHA-256 digests; whenever an authoritative source file changes, regenerate and verify the corresponding assets or JSON reports according to its manifest contract.

Wall-clock build times depend on CPU architecture, OS, Python/library versions, and system load; any benchmark report should record those parameters alongside run counts and aggregation statistics.

## Course Entrypoints

From the [GitHub Pages Course Home](https://nanless.github.io/microphone-array-tutorial/), learners can explore interactive wavefront diagrams, audition real 15-mic LOCATA room recordings comparing a single mic, delay-and-sum, and MVDR + postfiltering, and choose tailored study tracks across Foundations, Core Algorithms, Industrial Practice, and Frontier Topics. The [Industrial Engineering Hub](https://nanless.github.io/microphone-array-tutorial/site/#course-engineering) links directly to cascade topology, latency/compute budgeting, and acceptance testing across chapters and upstream source manuals.

Pushing updated website or companion media files to `main` triggers the [GitHub Pages workflow](../.github/workflows/pages.yml) to deploy `site/`, figures, audio assets, and the monograph PDF. For local inspection, open [`site/index.html`](../site/index.html) directly in any browser.

Course landing-page templates, CSS styles, and interactive scripts reside in [`course_home/`](course_home/). After editing them, run from the repository root:

```bash
.venv/bin/python scripts/course_home/export_portable.py
.venv/bin/python scripts/course_home/export_portable.py --check
.venv/bin/python scripts/build_site.py
```

The [LOCATA audio comparison clips and level SVG](../assets/readme/cases/locata/NOTICE.txt) are generated by `scripts.course_home.prepare_locata`. Once the six SHA-256-verified raw LOCATA files and `ffmpeg` are available locally, run `.venv/bin/python -m scripts.course_home.prepare_locata /path/to/extracted --check` for read-only replay (omit `--check` first when regenerating, then re-run `--check` and `build_site.py`).

Modifying only `course_home/` templates, styles, or interactive scripts updates the website input digest without affecting the combined PDF monograph. If shared logic in `build_site.py` changes, rebuild the PDF as well using the sequence below.

**Release & Acceptance Notes**

- **Bookmarks & Manual Spot-Checks**: Top-level PDF bookmarks cover the Overview, 16 main/frontier chapters (Chapters 0–15), and 2 appendices (Chapters 16–17); level-2 bookmarks map to `h2`/`h3` sections; and source `h4` headings across Chapters 0–15 and Appendices A/B form level-3 bookmarks nested under their parent sections. Every bookmark targets an exact PDF named destination derived from the HTML heading `id` (never first-text matching that could land on the TOC instead of the body); `quality_check.py` independently verifies page numbers and viewport coordinates for every bookmark.
- **Offline MathJax SVG & SRE Formula Tagging**: The combined PDF renders TeX via vendored MathJax 3.2.2 SVG + SRE 4.0.6 English rules ([`vendor/mathjax-3.2.2/README_EN.md`](vendor/mathjax-3.2.2/README_EN.md)), binding every formula occurrence (including TOC duplicates) to its TeX digest, exporting MathML, generating non-empty English structural `ActualText`, verifying unique MCIDs and visible vector paths after printing, and promoting structure nodes from `Figure` to `Formula`. Historical browser and font calibration snapshots are archived in [`2026-10-05-pdf-formula-audit.json`](../reviews/2026-10-05-pdf-formula-audit.json) (13,652 formula instances), [`2026-10-05-pdf-browser-controls.json`](../reviews/2026-10-05-pdf-browser-controls.json) (19 initial controls), and [`2026-10-05-pdf-browser-controls-calibrated.json`](../reviews/2026-10-05-pdf-browser-controls-calibrated.json) (24 closed-loop font/rule controls: 2 nominal passes and 22 caught faults); release QA still requires opening the final A4 PDF to inspect formulas, wide tables, code blocks, figures, and page breaks visually.
- **Scale, Font Metrics & Page Transform Gate**: PDF body prose is `16 px` with MathJax at `100%` (website MathJax renders at `110%` with horizontal scroll containers for wide equations). Loading `MathJax_Math-Regular.woff` calibrates `ex` (`0.442em` x-height) with synthetic bold/italic disabled. Post-print verification checks body text transformation matrices: nominal CSS-px-to-PDF-pt scale is `0.75`, and any drop below `0.74` aborts the build to catch whole-book page shrinking caused by an overflowing table or equation.
