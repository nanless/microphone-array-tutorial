实验条件和数字怎么算

两路是合成节奏。模型只模拟四支等间距麦克风的整数到达时差，所有麦等增益，没有反射、额外噪声或自动方向估计。

用相同的补等量分别处理 A 和 B 的已知分量，再各自把整段输出的平方和除以单支麦收到该分量的平方和。保留了延迟尾部；百分比用浮点分量计算，播放器播放的是二者相加后量化的单声道 WAV，无逐段归一化。
