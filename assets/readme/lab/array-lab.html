四支麦，听哪边？

同一组四通道录音，只改变补偿时差的对齐方向：左边 A 是长音（1000/3000 Hz），右边 B 是成对短促敲击音。先猜哪一侧会变轻，再点击播放对比。

01 / 选择拾音模式并试听

建议先调低耳机或音箱音量。每次切换后自动生成对应 WAV，从头播放 3 秒片段。

实验物理假设与精确复算说明

两路声源均为确定性数学合成信号。模型模拟四支等间距麦克风的整数采样到达时差，各通道等增益，不含墙面反射、传感器底噪或盲方向估计。

程序对 A、B 两个已知分量施加完全相同的通道延迟并求四路均值，再将整段输出（含完整延迟尾部）的平方和除以单麦对应分量的平方和得到保留功率比。播放器输出为两分量相加后按同一增益量化的 16-bit PCM WAV，不做逐段峰值归一化。
