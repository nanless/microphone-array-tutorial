# MacBook Air 内置音频延迟实测

2026-11-12，Asia/Shanghai。MacBook Air（Mac17,3），macOS 26.6.1（25G76），Core Audio / PortAudio 19.7.0-devel。48 kHz 双工流。程序从内置麦克风端点读取一路音频，并把同一个低幅探测音送到内置扬声器端点的两路输出。这里记录的是应用通道数。开始前系统播放音量读数为 26%，结束后为 64%，没有逐次音量记录，不能按固定声压解释各组结果。没有外接音频设备参与测量。位置、房间距离与声压未另行标定。

## 声学回采

程序播放 20 ms、900–4500 Hz 的扫频脉冲，再在麦克风实际录到的数据中找归一化互相关峰。偏移从提交探测音的样本索引量到录入的对应样本索引，包含播放、声学传播、录入和主机缓冲。分别重新打开一次双工流。

| 回调块长 | 有声测次 | 回采偏移中位数 | 该次流内范围 |
| ---: | ---: | ---: | ---: |
| 128 点 | 20 | 106.31 ms | 106.31–106.31 ms |
| 480 点 | 20 | 115.73 ms | 115.73–115.73 ms |

无输出对照有 8 个搜索窗口，绝对相关峰最大 0.109。有声测试中，首次回采搜索窗的绝对相关峰最低为 0.659。另一次 128 点双工流的首峰偏移为 105.60 ms，说明同一条流内结果稳定，重开流的起始配对可能不同。此处没有把两条流之差归因于单一缓冲。 [声学环回与归一化相关测量方法](https://source.android.com/docs/core/audio/latency/measure#technique)

## 同一条流的转发对照

在同一条 128 点双工流内，交替把探测音的回采片段延后 60 ms、100 ms 再送入扬声器，每档 16 次。分析验证了每个转发样本都来自预定的采集位置，转发未触发限幅。用归一化互相关在真实麦克风录音中找再次回采的波形。第二次用实际提交的 2700 点转发波形作模板，得到的匹配偏移再加插入缓冲，给出两次回采中对应片段的间隔。相关峰代表窗口内最佳匹配，物理直达时刻需另行确认。

| 程序插入缓冲 | 两次回采中对应片段的间隔，中位数 | 同一标签的 ADC→DAC 回调时间戳估计，中位数 |
| ---: | ---: | ---: |
| 60 ms | 165.60 ms | 73.58 ms |
| 100 ms | 205.60 ms | 113.58 ms |

16 对试次的声学间隔差为 40.00–40.02 ms。配对时间戳的差约为 40.00 ms。再次回采间隔包括另一程扬声器到麦克风的路径，时间戳估计使用驱动报告的首样本时刻及块内偏移。两者的绝对值采用不同测点，不可直接替换。此次也未使用独立双通道记录仪校准 ADC→DAC 的绝对时刻。四个正式流的 15,314 次回调中，未收到 PortAudio 状态标志。这是接口报告的状态。 [PortAudio 回调时间戳定义](https://files.portaudio.com/docs/v19-doxydocs/structPaStreamCallbackTimeInfo.html)

此次结果适用于本机的单麦路径与测试中的短时负载。多麦同步、DOA、波束形成、产品压力条件的延迟分布和功耗未从这些数字推断。保存了测量源码、每次探测的数值和回调日志。测试产生的麦克风波形未收入仓库。测量程序、分析程序、回调日志和逐次结果保留该次运行归档的原始字节。

## 核对历史记录

从本目录运行 `shasum -a 256 -c sha256.txt` 核对文件，然后运行 `python3 verify_timestamps.py`。后者用回调日志重算 32 组 ADC 到 DAC 的标签配对，并换算已保存的声学峰索引。重新寻找相关峰需要再录一次。本次转发组的每个缓冲长度以逐次 `programmed_delay_ms` 为准，组外层的同名字段只记录起始档。

## 复跑

从本目录开始，在有 PortAudio 头文件、动态库和 NumPy 的 Mac 上运行以下命令。新数据写入单独的临时目录。探测会短时播放，麦克风波形写入测试目录。先用无转发条件确认本机的首次到达落在样本区间内，再跑固定门控的配对条件。本机门控起点为 4100 点，长度 2700 点，第二次回采搜索范围为转发后 75–150 ms。

```sh
src="$(pwd)"
work="$(mktemp -d)"
cd "$work"
cc -O2 -Wall -Wextra -I/opt/homebrew/include "$src/bench.c" \
  -L/opt/homebrew/lib -lportaudio -o bench
./bench null 128 8 1 0 0 0 >null.device.txt
./bench base128 128 20 0 0 0 0 >base128.device.txt
./bench base480 480 20 0 0 0 0 >base480.device.txt
./bench paired 128 32 0 -2880 4100 2700 >paired.device.txt
python3 "$src/analyze.py" .
```
